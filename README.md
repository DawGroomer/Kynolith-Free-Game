# Kynolith Free Game

> **RESEARCH PURPOSES ONLY**

This repository is for research purposes only.

The game is mobile only: Android and iOS. It uses Godot 4.7.x, GDScript only, and the Compatibility renderer.

KYNO is earned in play only. It has no cash value, cannot be traded, has no wallet or blockchain, and is never sold.

Only CANON items approved by Will Harris are canon.

All lore is authored by Will Harris. AI drafts never go in the repo.

Only approved canon content, CI logs, and PR attachments are public.

## Folder layout

| Path | Purpose |
| --- | --- |
| `Data/` | Structured project data. |
| `Docs/canon/` | Canon documentation. |
| `Docs/plans/` | Project plans. |
| `Docs/adr/` | Records of architecture decisions. |
| `Tools/` | Development tools used to check and maintain the project. |
| `Metrics/` | Task event records, the event schema, and schema fixtures. In Metrics/tasks.jsonl, `date` is the US Central calendar day and `merged_at` is a UTC timestamp, so they can differ. |
| `game/` | Godot 4.7.x project for the mobile game. |
